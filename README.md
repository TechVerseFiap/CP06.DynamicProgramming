## Environment

Python 3.10 or newer is recommended. Install dependencies with:

```bash
python -m pip install -r requirements.txt
```

## Question 1 run

```bash
python questao_01/main.py
```

The command runs the six-SKU Brute Force benchmark, compares two seeded GA
configurations on the official catalog, then passes the selected policy to
Greedy. It writes financial results and before/after promotion accounting to
`questao_01/resultados/resultado_q1.json`. Scenario overrides are available;
run `python questao_01/main.py --help` for options.

## Question 2 run

```bash
python questao_02/main.py
```

This question uses three algorithms: Monte Carlo estimates demand and cash,
Dynamic Programming builds the weekly price policy, and Greedy allocates the
weekly promotion budget. Independent Monte Carlo scenarios then validate the
complete plan against the debt payments in weeks 4, 8, and 12.

To set the simulation seed and scenario counts explicitly:

```bash
python questao_02/main.py --seed 1232 --cenarios 2000 --validacao-cenarios 5000
```

Construction requires at least 2,000 scenarios; independent validation requires
at least 5,000. Without `--seed`, the construction seed is the official
`seed_final + 201` (1232 for G01). Validation uses the construction seed plus
1,000,003. These options do not modify the official input files.

The command writes `questao_02/resultados/resultado_q2.json` with the weekly
price policy, promotions, payment probabilities, expected final cash, and P10
final cash. See `run_q2()` and `main()` in `questao_02/main.py` for the flow and
output assembly, and `docs/decisoes.md` for model assumptions.

Question 2 estimates outcomes with Monte Carlo, compares risk-aware and

validates the selected policy (2,000 and 5,000 scenarios by default).
Run `python questao_02/main.py --help` for scenario overrides. Run
`python tools/evidence.py` to regenerate CSV/SVG evidence and
`python tools/benchmark_performance.py` to reproduce performance tables.
See `docs/decisoes.md`, `docs/complexidade.md`, and `docs/desempenho.md` for
assumptions and measured results.

## Official instance status

The four official CSV/config files and generated manifest are in `data/`.
`data/official_inputs.py` verifies per-file SHA-256 values, the combined hash,
and instance ID before loading either catalog. Do not edit generated inputs
manually. To regenerate, run the notebook with the same group/member RMs, then
copy the four files and `manifesto_dados.json` from `dados_gerados/G01/` into
`data/` unchanged; rerun either main to verify the hashes.
