# Decisões de projeto

A solução adotada prioriza clareza e reprodutibilidade sobre sofisticação desnecessária.

- A questão 1 usa estratégia de avaliação por preços permitidos.
- A questão 2 usa DP por semana e estoque remanescente.
- O Greedy é usado como alocador de incentivo promocional.
- Os parâmetros são configuráveis por CLI e seed fixa.
