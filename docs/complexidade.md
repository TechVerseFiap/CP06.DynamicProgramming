# Complexidade

## Questão 1
- Brute Force: O(n * p^n) para n SKUs e p preços permitidos.
- Algoritmo Genético: O(G * P * n) em geral.
- Greedy: O(n log n) pela ordenação dos itens.

## Questão 2
- Monte Carlo: O(C * F), com C cenários e F fatores aleatórios.
- Programação Dinâmica: O(S * W * P).
- Greedy: O(n log n).

Onde:
- S = estoque máximo;
- W = semanas;
- P = preços permitidos;
- C = cenários;
- n = itens do catálogo.
